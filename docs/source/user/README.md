# User documentation

Follow the [usage tutorial](USAGE.md) to build an image for a supported board. The
[configuration reference](CONFIGURATION.md) explains the layer's settings and how
[BitBake](https://github.com/openembedded/bitbake) and [kas](https://github.com/siemens/kas) load them.

## Files

- [CONFIGURATION.md](CONFIGURATION.md) — Explains each setting in the layer's configuration, recipes, kas fragments, and CI workflows.
- [README.md](README.md) — Introduces the user documentation.
- [USAGE.md](USAGE.md) — Builds an image for a supported board and shows where the result is.
