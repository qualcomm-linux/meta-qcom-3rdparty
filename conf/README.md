# Layer configuration

[BitBake](https://github.com/openembedded/bitbake) configuration that registers the layer and defines its machines. The
[configuration reference](../docs/source/user/CONFIGURATION.md) explains each
setting.

## Folders

- [machine/](machine/README.md) — Defines the boards this layer supports.

## Files

- [README.md](README.md) — Describes the layer configuration.
- [layer.conf](layer.conf) — Registers the layer, its recipes, its dependencies, and its compatible Yocto Project release.
