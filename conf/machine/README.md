# Machines

Set `MACHINE` to a file name without `.conf` to build for that board. The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machines)
compares their settings.

## Files

- [README.md](README.md) — Lists the supported boards.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Radxa Dragon Q6A (QCS6490), whose boot firmware stays in SPI NOR flash.
- [rubikpi3.conf](rubikpi3.conf) — Thundercomm RUBIK Pi 3 (QCS6490).
