# Package groups

Package groups that list each board's firmware; the board's machine
configuration recommends them.

## Files

- [README.md](README.md) — Describes the package groups.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Lists the Radxa Dragon Q6A firmware and its Hexagon DSP binaries.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Lists the RUBIK Pi 3 firmware.
