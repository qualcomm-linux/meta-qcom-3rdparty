# Dynamic layers

Recipes and appends that [BitBake](https://github.com/openembedded/bitbake) parses only when another layer is in the build,
as `BBFILES_DYNAMIC` in [`conf/layer.conf`](../conf/layer.conf) selects.

## Folders

- [qcom-distro/](qcom-distro/README.md) — Applies when [meta-qcom-distro](https://github.com/qualcomm-linux/meta-qcom-distro) is in the build.

## Files

- [README.md](README.md) — Describes the dynamic layers.
